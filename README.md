# CNCU-01 4-Layer PCB Redesign

![PCB 3D](docs/PCB_3D.png)

## Overview

This project is a PCB redesign of the open-source CNCU-01 controller board.

The original design was migrated from a 2-layer PCB to a 4-layer stackup.

## Layer Stackup

![Layer Stackup](docs/PCB_STACKUP.png)

## My Contributions

- Migrated PCB from 2 layers to 4 layers
- Defined PCB stackup
- Calculated controlled impedance using SI9000
- Configured differential pair routing
- Performed DRC verification
